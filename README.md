# EMR30 · The first year

A bilingual, responsive Physics study companion for **10 November 2026–10 November 2027**.

- 262 study days, 104 Friday/Saturday rest days, 2,096 planned hours.
- Full reading plan: 225 learning days, 25 review/lab days and 12 final assessment days.
- Exact physical PDF page ranges, printed page labels, edition and filename for 20 books.
- Bangla/English instructions; light/dark theme; calendar and full-year topic/course search.
- Block checklists, daily notes, self-scores, 50-minute focus timer and printable daily plans.
- Device-local progress with JSON backup export/import. No login, tracking or automatic cloud sync.
- Offline core after an initial successful online load. Textbooks are not included.

Published with GitHub Pages from the root of `main`. Static HTML, CSS and JavaScript; no build or server dependencies.

## Local preview

Serve this folder with any static HTTP server, for example `python -m http.server 8080`, then open `http://localhost:8080`.

## Data & privacy

`data.json` is the complete schedule derived from the audited EMR30 Year 1 plan. All page ranges are inclusive physical file pages. They apply to the exact editions and PDF filenames in the Bookshelf. No textbook files or absolute personal filesystem paths are included.

Progress is stored in the current browser. Export regularly; import the JSON backup on another device to transfer it. An import replaces records for the dates present in the backup, while retaining other dates. The focus timer is a session tool, not a measurement of completed study hours. Finishing a checklist does not certify mastery.
